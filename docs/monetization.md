# Network effects and monetization

All prices are brainstorm hypotheses, not validated.

## Layers

```text
Factory → Agents → Network → Marketplace → Economy
```

Agent unit produced by the factory:

```text
Agent = Identity + Voice/Avatar + Skills + Memory + Tools + Policies + Reputation
```

## Network effects

| Effect | Loop |
|---|---|
| Agent → agent capability | More agents → more capabilities → each agent more useful → more users → more agents |
| Two-sided business ↔ user | More business agents → more useful to users → more valuable to businesses |
| Skills marketplace | More developers → more skills → better agents → more customers → more developer revenue |
| Reputation graph | Completed interactions → reputation signals → better discovery → more interactions |
| Data / factory | Deployed agents → evaluations → patterns → factory improvements → better agents |
| Entity graph | Rooms reference rooms → each event reaches several audiences |

Reputation signals: completion rate, satisfaction, latency, accuracy, refund rate,
conversion rate, tool reliability, human escalation rate, cost.

The data effect uses aggregated, evaluated signals with privacy boundaries, not raw
private conversations.

## Reinforcing loops

| Loop | Cycle |
|---|---|
| Creator | creators → agents → users → revenue → creators |
| Business | businesses → useful agents → consumers → leads/transactions → businesses |
| Capability | developers → skills → capable agents → demand → developers |
| Intelligence | interactions → evaluations → better factory → better agents → interactions |
| Economic | agents → transactions → revenue → participants → agents → transactions |

## Marketplaces

| Marketplace | Supply | Revenue mechanism |
|---|---|---|
| Agents / templates | Reusable vertical agents (realtor, recruiter, tutor, support engineer, podcast host) | Clone → customize → deploy; creation + operation fees |
| Skills | Integrations and capabilities (CRM, payments, scheduling, research, translation) | Commission, est. 10–30% |
| Identity / media | Voices, avatars, personalities, room designs, presentation styles | Licensing, revenue share with creators |
| Services / transactions | Agent-provided services discovered by other agents | Transaction fee |

Agent-to-agent commerce example: personal agent → discovery → ranked provider agents by
reputation, price, capability → selected agent → transaction → fee.

## Outcome pricing

Charge per economic outcome instead of per minute or token, so revenue tracks value
created rather than inference consumed.

| Outcome | Example price |
|---|---|
| Qualified lead | $3 |
| Booked appointment | $10 |
| Resolved support case | $25 |
| Completed transaction | 2% |

## Room tiers (growth engine)

Monetize only after the network starts moving.

| Tier | Price hypothesis | Includes |
|---|---|---|
| Free | $0 | Public room, public-source agent, basic claim, corrections |
| Pro | $99–299 / month | Official agent, custom voice, analytics, private knowledge, lead capture, scheduled media, integrations |
| Business | $500–2,000 / month | Multiple agents, CRM, support and sales workflows, API, advanced analytics |
| Enterprise | Contract | Governance, SSO, private deployment, audit, custom models and evals |

Later: transaction revenue.

## Positioning

Not "the best multimodal voice-agent builder". Instead: the factory that creates AI
entities, the network where they operate, and the economic system through which they
serve humans and other agents.
